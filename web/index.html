A real compiler.
Write a C program with the custom words below. Ordinary C types such as int and char still work. The replaced standard names are rejected in your code.
From your code to the result
The original C frontend checks your words and translates them into standard C. Clang 22 compiles and links that C into WebAssembly. A WASI runtime runs it in a separate browser worker. Your code and input stay on your device.
Input, errors, and stopping a program
Input can be entered before Run or sent when the program asks. The program waits for input until you send a value, Send EOF, or press Stop. Click an error to jump to the original line and column. Compile again after editing to refresh error locations. Stop terminates the worker; the next run reloads the runtime.
Execution has no time limit. Compilation has a 90-second limit, and the first toolchain load has a 180-second limit. Source is limited to 1 MiB and each input submission to 64 KiB. The console keeps recent output in a bounded buffer without stopping the program.
Browser version and compatibility
This version uses Clang and WASI, rather than desktop GCC. Standard console C is supported, subject to WASI and this toolchain. Desktop windows, operating-system commands, native libraries, sockets, and a real machine filesystem are not provided. Unsafe C can still crash a program or consume browser memory. The worker can be stopped.
The first compile downloads about 29 MB of tools from this site. It needs a recent browser with WebAssembly. Browser caching may make later loads faster; fully offline installation is not included.
Files, privacy, and credits
The editor keeps one draft in this browser’s local storage. Use Download to keep a copy. Opening a file or example replaces the editor contents. No accounts or API keys are needed. Source and input are never sent for compilation. Hosting can still record ordinary page and asset requests.
My C Compiler uses the project’s C keyword frontend, CodeMirror 6 for editing, and @live-codes/clang-wasm with LLVM, Clang, and WASI dependencies. Read the C frontend ↗ · Third-party notices ↗
